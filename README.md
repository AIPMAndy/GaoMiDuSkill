## 🎯 这是什么？

一个专门用于创作**高信息密度**内容的 Claude Code Skill。杜绝废话、空话、套话，确保每个字都承载价值，每句话都可验证。

**核心公式**：
```
信息密度 = 有效信息量 / 总字数

有效信息 = 可验证的事实 + 可操作的洞察 + 新颖的观点
```

**目标**：每 100 字至少包含 3-5 个可独立验证的信息点。

## ✨ 核心特色

### 📊 可验证性标准

所有信息必须满足以下至少一项：
- ✅ **可溯源**：有明确的数据来源（论文、报告、数据库）
- ✅ **可重现**：读者可以通过描述的方法得到相同结果
- ✅ **可反驳**：论点足够具体，可以被证伪
- ✅ **可量化**：用数字、比例、时间等精确表述

### 🚫 禁止使用

- "很多人认为"（谁？多少人？什么研究？）
- "大幅提升"（提升多少？相对于什么基线？）
- "众所周知"（谁知道？有统计吗？）
- "非常重要"（重要性如何衡量？）

### 🛠️ 8 大高密度写作技巧

1. **数据前置，结论后置** - 先给数据，再给结论
2. **替换模糊词为精确值** - "很多" → "73%的受访者"
3. **使用信息串结构** - 一句话包含多个信息点
4. **删除脂肪词** - 去掉"首先"、"值得注意的是"等废话
5. **案例必须完整可查** - 时间、公司、数据、来源
6. **层次化信息结构** - 金字塔原则，结论先行
7. **替换抽象名词为动词** - "进行分析" → "分析"
8. **信息前置，解释后置** - 先给答案，再说原因

## 🎨 内容类型模板

### 模板 1：数据驱动分析
- 核心发现 + 数据解读 + 底层原因 + 未来预测
- 强制要求：所有数据标注来源

### 模板 2：案例拆解
- 基本信息 + 核心动作 + 可复制要素 + 不可复制要素
- 强制要求：时间、公司、具体数据、信息来源

### 模板 3：技术深度解析
- 技术原理 + 性能指标 + 实际应用 + 技术限制 + 演进方向
- 强制要求：对比基准、具体数值

### 模板 4：对比分析
- 对比维度表格 + 优势场景 + 选择决策树
- 强制要求：同一口径对比

## ✅ 质量检验清单

写完后，逐项检查：

### 信息密度检验
- [ ] 每100字包含至少3个可验证信息点
- [ ] 删除所有"脂肪词"和空洞形容词
- [ ] 没有"很多"、"大幅"、"显著"等模糊表述
- [ ] 所有数字都有来源标注

### 可验证性检验
- [ ] 所有数据都有明确来源（论文/报告/数据库）
- [ ] 所有案例都有时间、公司、具体数据
- [ ] 所有对比都基于同一口径
- [ ] 读者可以通过来源验证每个关键信息

### 可读性检验
- [ ] 结论前置，读者3秒内知道核心观点
- [ ] 使用短句（平均15-25字/句）
- [ ] 避免连续3句以上的长句
- [ ] 使用列表/表格/图表辅助理解

### 价值检验
- [ ] 文章提供了新信息（不是"众所周知"的事）
- [ ] 文章提供了新视角（不是重复别人的观点）
- [ ] 读者读完能获得可操作的知识
- [ ] 删掉任意一段，文章会失去价值

## 🎓 创作原则

1. **信息密度 > 文字优美** - 精确比华丽重要
2. **数据 > 观点** - 用数据说话，不靠主观判断
3. **具体 > 抽象** - "转化率从2.1%升至5.7%" > "大幅提升"
4. **可验证 > 可信** - 提供来源，让读者自己验证
5. **删减 > 增补** - 写完后删掉30%废话，密度自然提升
